# Mac 启动台太丑？我自己重做了一个

我自己独立开发了一个 macOS 应用管理工具：**MacApp Box**。

起因很简单：Mac 上的应用越来越多，再加上 Parallels Desktop 虚拟机里的 Windows 软件，找东西很乱；原生启动台又很难按自己的工作方式维护。

现在它做了这些：

- macOS 与 Windows 分类完全独立
- Windows 应用来自 Parallels 虚拟机里已安装的软件，不是原生 Windows 版，也不会直接运行 exe
- 分类、文件夹、拖动排序、多选移动
- 保存多个布局，打乱后可恢复
- 自动分类审核、常用软件、深度卸载
- 12 套主题、10 种背景、系统字体自定义
- 简体中文 / English 实时切换

目前 **v0.2.0 免费开源**。开发版使用 ad-hoc 签名；如果 macOS 首次打开时拦截，请在“隐私与安全性”中允许打开。

GitHub 搜索：`WilliamGvyan/MacAppBox`
